SECTION 01

What's in the Bundle

The MatricX Bundle includes both MatricX Pro and MatricX Bake, in full. Every bundle tier includes the complete feature set of each add-on — higher tiers add licensing scope, support, and collaboration, not extra core features.

MatricX Pro

Build the surface. 55 premade materials, custom material presets, 15 imperfection types, paint masks, decals & trim sheets, and live mapping compensation.

MatricX Bake

Bake the textures. Clean PBR maps from any material, one shared texture set, robust bake UVs, ORM/ARM/RMA packing, decal baking, and FBX/GLB export.

This guide is a quick reference for using both add-ons together. For the complete, detailed documentation of each add-on individually, see Section 07.

SECTION 02

Install Both Add-ons

MatricX Pro and MatricX Bake are installed the same way, and independently of each other — each is provided as two ZIP formats.

PackageUse ForInstall Path
MatricX_Pro.zipClassic Blender addon install.Edit > Preferences > Add-ons > Install
MatricX_Pro_Extension.zipBlender Extension style install.Edit > Preferences > Add-ons > Install from Disk
MatricX_Bake_1.6.2.zipClassic Blender addon install.Edit > Preferences > Add-ons > Install
MatricX_Bake_1.6.2_Extension.zipBlender Extension style install.Edit > Preferences > Add-ons > Install from Disk

Both add-ons can be installed and enabled at the same time with no conflicts. MatricX Pro is opened from 3D View > Sidebar > MatricX, and MatricX Bake from 3D View > Sidebar > MatricX Bake.

SECTION 03

The Combined Workflow

MatricX Pro and MatricX Bake are built to work as one continuous pipeline, not two separate tools you happen to own.

  1. Build the surface in MatricX Pro — apply a material, layer in imperfections, paint masks where needed, add decals or trim sheets.
  2. Bake it in MatricX Bake — select the object or collection, prepare UVs if needed, choose your bake maps, and bake. MatricX Bake automatically preserves MatricX Pro's procedural imperfection placement, so the baked result matches what you built.
  3. Export — package the model, textures, and an asset manifest as FBX or GLB, ready for your game engine.

Why this matters: MatricX Pro's imperfection layers frequently use Object or Generated coordinates inside nested node groups. MatricX Bake stores each source object's original coordinates and substitutes them only on temporary copies, so dirt, wear, noise, and bump masks keep their original placement when baked. Your source materials and node groups are never modified.
